# DNA01 public scoring

`score_dna01.py` is the only public entry for model representations. `dna01_core.py` contains shared frozen validation, aggregation, bootstrap and atomic-publication functions; it is not a second CLI.

The user supplies only primary and repeat model Forward outputs. The scorer then:

1. validates the formal object coverage plus the relation, anchor and fold references required for scoring;
2. validates exact representation coverage, dimensions, finite values and deterministic repeat equality;
3. fits one weighted shared affine operator for each outer fold using the other four folds;
4. computes held-out residuals, frozen anchor target scales, specificity and cycle diagnostics;
5. applies `a/(a+e)` and aggregates view → parent locus → dependency cluster;
6. applies the frozen dynamic-range gate and 20,000-draw dependency-cluster bootstrap;
7. atomically publishes the per-view `F_credit`, parent and dependency-cluster F ledgers, formal F bootstrap draws and final result.

The full input contract and runnable command are in [`../README.md`](../README.md). Environment setup is in [`ENVIRONMENT.md`](ENVIRONMENT.md).

## Generated ledger columns

| Column | Definition |
|---|---|
| `relation_id` | Frozen FWD/RC relation ID. |
| `forward_object_id`, `rc_object_id` | Formal model-input objects compared by this relation. |
| `outer_fold_id` | Held-out fold used for this relation. |
| `cluster_id` | Bootstrap/dependency unit. |
| `parent_locus_id` | Intermediate aggregation unit. |
| `view_id` | Frozen view identity. |
| `evaluation_status` | `SCORED` or `UNSCORABLE`. |
| `unscorable_reason` | Empty for scored rows; otherwise the reason the formal relation score is undefined. |
| `residual` | Euclidean held-out affine prediction error `e_i`. |
| `target_scale` | Median observed-target to RC-anchor distance `a_i`. |
| `F_credit` | `a_i/(a_i+e_i)`, or undefined when `a_i=0`. |
| `specificity` | Tie-aware fraction of frozen wrong-target distances exceeding the residual. |
| `cycle_residual`, `cycle_scale`, `normalized_cycle` | Raw two-application affine cycle diagnostic, its scale, and their ratio. |
| `anchor_target_distance_1` … `anchor_target_distance_8` | The eight frozen wrong-target distances used for specificity and interpretation. |
| `target_to_anchor_distance_1` … `target_to_anchor_distance_8` | The eight observed RC-target to anchor distances whose median is `target_scale`. |

`INDIVIDUAL_SCORES.tsv` is a canonical public output generated by the scorer. Users are never required to construct it. `PARENT_F_LEDGER.tsv`, `DEPENDENCY_CLUSTER_F_LEDGER.tsv`, `F_BOOTSTRAP.npy` and `FORMAL_RESULT.json` provide the complete F-only aggregation chain.

Top-level `status=PASS` records successful validated execution. `score_status` separately records whether the frozen dynamic-range gate allowed the primary score to be reported.
