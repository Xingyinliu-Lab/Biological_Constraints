# PS02A NW–BLOSUM62 primary comparator

This is the frozen Level-1 raw-sequence explanatory reference for PS02A. It
uses EMBOSS Needle 6.6.0.0 with EBLOSUM62, fixed gap penalties and normalized
global-alignment similarity. It does not use family/clan labels, profiles,
retrieval, taxonomy, structure or pretrained representations to compute pair
similarity.

The method contract is
[`method/PS02A_NW_BLOSUM62_COMPARATOR_CONTRACT_v0.1.1_FROZEN.json`](method/PS02A_NW_BLOSUM62_COMPARATOR_CONTRACT_v0.1.1_FROZEN.json).
Environment and EMBOSS requirements are in [`ENVIRONMENT.md`](ENVIRONMENT.md).

## Run the complete comparator

From the repository root:

```bash
python constraints/protein_sequence/PS02A/comparators/nw-blosum62-primary-comparator/code/run_ps02a_nw_blosum62_formal.py \
  --needle /path/to/emboss-6.6.0.0/bin/needle \
  --output-dir work/PS02A/nw-blosum62 \
  --workers 8
```

The wrapper validates the frozen RefSet and comparator implementation, records
the SHA256 of the supplied Needle executable, materializes pair scores and leaf
measurements, then calls PS02A's public scoring core. EMBOSS Needle 6.6.0.0
and the frozen algorithm parameters remain required; byte identity with the
historical executable is provenance, not a public admission gate. `--workers`
changes only parallel execution and does not change the method. An existing
output directory is never overwritten.

## Inputs and fixed method

- FASTA: `refset/endpoint_sequences.faa`, all 13,720 released Forward objects;
- bundles: `refset/FORMAL_BUNDLE_LEDGER.tsv.gz`, all 10,072 contrasts;
- normalized similarity: `2*s(x,y)/(s(x,x)+s(y,y))`;
- matrix: EBLOSUM62;
- gap open/extend: 10.0/0.5;
- terminal gaps penalized with end open/extend 10.0/0.5;
- relation credit, hierarchy and 20,000-draw anchor-clan bootstrap: the same
  public PS02A score core used for model representations.

## Generated outputs

| Path | Contents |
|---|---|
| `measurement/PAIR_SCORE_CACHE.tsv.gz` | pair IDs, raw Needle score, self scores and normalized similarity |
| `measurement/FORMAL_LEAF_SCORES.tsv.gz` | bundle-level positive and negative measurements |
| `measurement/CONTRAST_SCORE_LEDGER.tsv.gz` | bundle ID, two similarities, difference and F_credit (win 1; tie 0; loss -1) |
| `INDIVIDUAL_SCORES.tsv.gz` | public scorer ID-level output with dependency identities |
| `DEPENDENCY_AGGREGATION_LEDGER.tsv.gz` | dependency-level F aggregation generated by the public scorer |
| `SCORE_SUMMARY.json` | comparator F and F 95% CI, coverage and diagnostics |
| `EXECUTION_RELEASE.json` | method, code and output identities |

## Canonical reference result

[`results/`](results/) contains the formal F summary. Full relation and
dependency ledgers are regenerated into the user-selected output directory and
are not required as committed release artifacts.
