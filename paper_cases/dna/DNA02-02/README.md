# DNA02-02 paper cases

These five cases preserve the paper models' actual Forward implementations and bind their archived representations to the unique public DNA02-02 scorer.

- Scientific definition, released RefSet and scorer: `constraints/dna/DNA02-02/`
- Comparator execution and canonical results: retained only under `constraints/dna/DNA02-02/comparators/`
- Canonical public-scorer results: `models/<model_id>/output/DNA02-02_v0.1.5_f_only/`

No model was re-forwarded. The two archived, separately executed eval-mode Forward outputs for each model were rescored with the v0.1.5 public Constraint; checkpoint reload was not a formal v0.1.5 requirement. Each output contains 46,720 ID-level ladder scores, all hierarchy ledgers and aggregate F/F_95_CI. `V0.1.5_F_ONLY_PUBLIC_RESULTS.json` is the current results index.
