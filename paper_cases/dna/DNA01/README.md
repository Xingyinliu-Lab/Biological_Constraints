
# DNA01 paper cases

These five cases preserve the paper models' actual Forward implementations and bind their archived Forward outputs to the unique public DNA01 v0.5.4 scorer.

- Scientific definition, released RefSet and scorer: `constraints/dna/DNA01/`
- Comparator: retained only under `constraints/dna/DNA01/comparators/`
- Current public-scorer results: `models/<model_id>/output/DNA01_v0.5.4/`

No model was re-forwarded or refitted. The complete retained measurement ledgers were deterministically materialized into the v0.5.4 F-only output chain. Each current output includes per-view `F_credit`, parent and dependency-cluster F ledgers, formal bootstrap draws and final `F`/`F_95_CI`.
