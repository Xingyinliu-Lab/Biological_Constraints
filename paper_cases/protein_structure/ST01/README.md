# ST01 paper cases

These five cases record the paper models' structure Forward implementations and the outputs obtained by applying the same public ST01 scoring package available to external users.

Formal embedding NPZ files are not distributed. Reproduction begins with the
released ST01 RefSet and each model's public Forward guide, then runs the public
scorer on the newly generated embedding. The published outputs support
score-level comparison; they do not claim byte-identical identity to a
non-public historical embedding file.

No comparator implementation or result is duplicated here; the built-in geometry reference belongs to the ST01 Constraint release.

See [`CASE_INDEX.tsv`](CASE_INDEX.tsv) for the registered cases and result paths.
