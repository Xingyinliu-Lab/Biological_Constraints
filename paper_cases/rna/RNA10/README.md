# RNA10 paper implementation cases

Five paper-model cases use the unique RNA10 public F-only measurement and scoring pipeline. Each model directory contains Forward code, a scoring command, input identity metadata and released F-only outputs. The Forward NPZ is not redistributed; regenerate it from the released RefSet and model instructions before scoring.

[`CASE_INDEX.json`](CASE_INDEX.json) and [`PUBLIC_F_ONLY_RESULTS.json`](PUBLIC_F_ONLY_RESULTS.json) provide the current formal summaries.
