# RNA04 paper implementation cases

These five cases record the paper models as ordinary users of the released RNA04 Constraint. Each case owns its model Forward, then calls the same public F-only scorer available to third parties. Comparator execution and results remain inside the Constraint package.

See [`CASE_INDEX.json`](CASE_INDEX.json), [`PUBLIC_F_ONLY_RESULTS.json`](PUBLIC_F_ONLY_RESULTS.json) and the individual model directories.
