# RNA09 paper implementation cases

Five paper-model Forward implementations use the single public RNA09 F-only scorer. Each case contains its Forward implementation, scoring call, released F-only outputs and input identity record. The Forward NPZ is not redistributed; regenerate it from the released RefSet and model instructions before scoring.

Current case summaries are listed in [`CASE_INDEX.json`](CASE_INDEX.json) and [`PUBLIC_F_ONLY_RESULTS.json`](PUBLIC_F_ONLY_RESULTS.json). Comparator execution and results are in the public Constraint package.
