# Figure 4c statistical analyses

This package contains only the three formal tests displayed together in Figure 4c of the manuscript: between-Constraint unevenness, model-by-Constraint interaction, and overall model-order tendency. The original plot-source table uses historical panel identifiers B, C and D for these three small null plots; in the assembled manuscript they form Figure 4c.

`data/` contains the frozen 110-cell model F table. `code/` contains the three original analysis scripts with only the input/output paths adapted to this package. `results/` contains the published test summaries and the null draws used for the plots. No test was rerun or statistic changed during packaging. Comparator tests and other historical analyses are excluded.

Source folders: `Fig4/Global_knowledge_unevenness`, `Fig4/Global_knowledge_interaction`, `Fig4/Supplementary_rank_interaction_analysis`, and `Fig4/Global_structure_panels` under the project `analysis_and_visualization` directory.
